Green New Deal Plan - InternetEducation The city of Chattanooga Tennessee developed a municipal fiber optic internet system that is now up to 10GB speed (It is run by the city's municipal electricity company, EPB). The system covers the Chattanooga greater municipal area, which covers about an half million people. It cost $330 million to build, so if we wanted to cover 300 million people that would cost about $200 billion total. Over 20 years, that would be about $10 billion per year.
